# Notebooks

This directory contains python jupyter notebooks for this project. 

## Description

1. ``Do GWASH and LDSC on Real Summary Statistics.ipynb`` \
This notebook is used to run GWASH and LDSC on 89 Summary Statistics available from the ``sumstats/`` directory in https://github.com/TiffanyAmariuta/TCSC/. It also shows that our LDSC implementation is approximate to the released LDSC implementation given the same input data.
2. ``GCTA_validation.ipynb`` \
This notebook is used to show that our GCTA implementation is approximate to the released GCTA implementation given the same inputs.
3. ``Reproducibility.ipynb`` \
This notebook shows the code underlying results shown in the paper. It also shows that the data stored in ``save_data/`` are reproducible.
4. ``publication_mainfigs_notebook.ipynb`` \
This notebook contains code used to generate the main figures in the main text. It uses the data in ``save_data/``.
5. ``publication_suppfigs_notebook.ipynb`` \
This notebook contains code used to generate the supplementary figures in the main text. It uses the data in ``save_data/``.
